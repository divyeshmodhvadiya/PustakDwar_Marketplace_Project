# PustakDwar Marketplace

A warm, responsive marketplace for discovering affordable pre-loved books and passing favourite stories on to new readers.

## Features

- Browse books by title, author, category, price, and rating
- View individual book details
- Add books to a basket and adjust quantities
- Save books to a personal reading list
- Client-side navigation for marketplace, about, contact, login, and signup views
- Responsive layout for desktop and mobile screens
- Persistent basket and reading list data through browser `localStorage`
- Local fonts, logos, and book artwork with no external runtime dependencies

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

No build step or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/divyeshmodhvadiya/PustakDwar_Marketplace_Project.git
   cd PustakDwar_Marketplace_Project
   ```

2. Open `index.html` in a browser.
